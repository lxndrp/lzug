# TypeScript-Frontend-Referenz

TypeDoc erzeugt aus dem Angular-Quellcode und seinen TSDoc-Kommentaren eine Browser-Referenz.
Nach `task docs` ist sie unter
<a href="frontend/index.html">TypeScript-Referenz</a> verfügbar.

Die generierte Ausgabe liegt im selben lokalen Build und CI-Artefakt wie dieses Handbuch.
Die Toolentscheidung dokumentiert [ADR-0007](../decisions/0007-dokumentation-und-code-referenz.md).
