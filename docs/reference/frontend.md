# TypeScript frontend reference

The browser reference is generated by TypeDoc from the Angular source and its
TSDoc comments. It is deliberately kept as HTML because TypeDoc can consume the
locked TypeScript compiler directly.

This compatibility page moved to the
[TypeScript-Frontend-Referenz](../developers/reference/frontend.md). The
generated TypeDoc output is located under `developers/reference/frontend/` in
the built site.

For the tested toolchain and the reason TypeDoc was selected over Compodoc, see
[ADR-0007](../developers/decisions/0007-dokumentation-und-code-referenz.md).
