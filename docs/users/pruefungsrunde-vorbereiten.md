# Prüfungsrunde vorbereiten

1. Öffnen Sie **Prüfungshalbjahre** und legen Sie ein Sommer- oder Winterhalbjahr an.
2. Ordnen Sie dem Halbjahr einen Ausschuss zu. Dafür muss für den Ausschuss mindestens ein Prüfer hinterlegt sein. Die Anwendung erzeugt daraus eine ausschussbezogene Prüfungsrunde.
3. Pflegen Sie bei Bedarf unter **Ausschuss** Ausschüsse und Prüfer. Aktive Prüfer stehen für die Planung zur Verfügung.
4. Legen Sie unter **Prüfungsorte** die verfügbaren Orte an. Änderungen an Orten gelten für künftige Planungen.
5. Öffnen Sie **Prüflinge**, wählen Sie die aktuelle Runde und erfassen Sie die Prüflinge mit Prüfungsbedarf. Die Liste kann gefiltert und Einträge können bearbeitet oder gelöscht werden.

Das Dashboard zeigt den Status und die Kennzahlen der aktuell gewählten Prüfungsrunde. Wechseln Sie die Runde über **Prüfungshalbjahre**, bevor Sie Stammdaten oder Planung bearbeiten.
