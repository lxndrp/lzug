# Stammdaten

Unter **Ausschuss** pflegen Sie Ausschüsse und Prüfer. Aktive Prüfer werden bei der Planung berücksichtigt. Unter **Prüfungsorte** legen Sie die verfügbaren Orte an; Änderungen wirken auf künftige Planungen.

Unter **Prüflinge** erfassen Sie für die gewählte Prüfungsrunde Stammdaten und Prüfungsbedarf. Die Liste kann gefiltert werden; Einträge lassen sich bearbeiten oder löschen.
