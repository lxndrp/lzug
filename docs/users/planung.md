# Planung erstellen und bestätigen

Öffnen Sie für die aktuelle Prüfungsrunde den Bereich **Planung**.

1. Erfassen Sie den Planungsrahmen, insbesondere Zeitraum, Bundesland, Prüfungen pro Tag und gegebenenfalls eine Mittagspause.
2. Lassen Sie mögliche Prüfungstage berechnen oder legen Sie einzelne Tage manuell an. Aktivieren Sie nur Tage, die für die Planung verfügbar sind.
3. Erfassen Sie die Verfügbarkeiten der aktiven Prüfer für diese Tage.
4. Erzeugen Sie einen Planungsvorschlag über **Planung erzeugen**. Die Anwendung berücksichtigt die hinterlegten Tage, Prüflinge und Verfügbarkeiten und zeigt Hinweise zu unvollständigen Voraussetzungen an.
5. Prüfen Sie die vorgeschlagenen Tage, Termine und Besetzungen auf dem Dashboard. Ist der Vorschlag passend, bestätigen Sie ihn dort.

Ein bestätigter Plan ist in der aktuellen Anwendung nicht durch einen neuen Vorschlag ersetzbar. Prüfen Sie daher die Angaben und die angezeigten Hinweise, bevor Sie bestätigen.
