# Prüfungshalbjahre

Öffnen Sie **Prüfungshalbjahre**, um ein Sommer- oder Winterhalbjahr anzulegen. Ordnen Sie anschließend einen Ausschuss zu. Voraussetzung ist, dass für diesen Ausschuss mindestens ein Prüfer hinterlegt ist. Die Anwendung legt daraus eine ausschussbezogene Prüfungsrunde an.

Wählen Sie die gewünschte Runde, bevor Sie Prüflinge, Orte oder die Planung bearbeiten. Planungstage und bestätigte Termine bleiben an der jeweiligen Runde erhalten.
