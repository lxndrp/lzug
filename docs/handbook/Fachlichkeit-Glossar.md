# Glossar

Dieses Glossar legt die Begriffe der Business Domain einheitlich fest. Ein
Begriff hat in dieser Dokumentation genau die hier beschriebene Bedeutung.

| Begriff | Bedeutung |
| --- | --- |
| Ausschussmitglied | Person, die einem Prüfungsausschuss angehört. Sie kann ordentlich oder stellvertretend berufen sein und eine Rolle als Mitglied, Vorsitz oder stellvertretender Vorsitz innehaben. |
| Berufungsart | Formale Einordnung eines Ausschussmitglieds als ordentlich oder stellvertretend. Sie begründet keine unterschiedlichen fachlichen Befugnisse. |
| Besetzung | Zuordnung der regulären Prüfer:innen und des Fallbacks zu einem Prüfungstag und Tagesabschnitt. |
| Einzelbewertung | Individuelle Bewertung einer Prüfungsleistung durch eine Prüferin oder einen Prüfer. Sie ist noch nicht das verbindliche Ergebnis des Ausschusses. |
| Fallback-Prüfer:in | Zusätzlich eingeplante Person, die bei einem Ausfall als Ersatz bereitsteht und dies ausdrücklich bestätigen muss. |
| Fachgespräch | Leistungsbestandteil der mündlichen Prüfung, der am Prüfungstag individuell und anschließend gemeinschaftlich bewertet wird. |
| Gesamtbewertung | Verbindliche, vom Ausschuss gemeinschaftlich festgestellte Bewertung eines Leistungsbestandteils oder der gesamten Prüfungsleistung. |
| IHK | Stelle, die bei nicht herstellbarer Besetzung eines Prüfungstags über dessen Ausfall informiert wird. Weitere Rollen in den hier beschriebenen Prozessen sind noch offen. |
| MEP | Mündliche Ergänzungsprüfung. Sie wird als eigener Slot am Ende eines Prüfungstags geplant. |
| Prüfungsdurchgang | Ausschussbezogene Prüfungsrunde innerhalb eines Prüfungshalbjahrs. Er ist der Bezugspunkt für Planung, Prüfungstage und Prüfungen. |
| Prüfungshalbjahr | Sommer- oder Wintertermin eines Jahres, der die Prüfungsrunden der Ausschüsse zusammenfasst. |
| Prüfungsleistung | Dokumentation, Präsentation oder Fachgespräch eines Prüflings. |
| Prüfungsausschuss | Fachlich zuständiges Gremium für die Prüfungsrunde, Beratungen und Beschlüsse. |
| Prüfungstag | Konkret geplanter oder bestätigter Tag mit Prüfungsort, Slots und Besetzung. |
| Prüfungsslot | Konkreter Termin einer Prüfung innerhalb eines Prüfungstags. Reguläre Slots dauern 60 Minuten. |
| Prüfer:in | Ausschussmitglied, das Prüfungen durchführt oder Prüfungsleistungen bewertet. Ordentliche und stellvertretende Prüfer:innen sind fachlich gleichberechtigt. |
| Prüfling | Person, die in einem Prüfungsdurchgang einer Prüfung zugeordnet ist. |
| Präsentation | Leistungsbestandteil der mündlichen Prüfung, der am Prüfungstag individuell und anschließend gemeinschaftlich bewertet wird. |
| Reguläre Prüfer:innen | Prüfer:innen, die einem Tagesabschnitt zur Durchführung zugeordnet sind. Mindestens drei und alle drei Vertretungsseiten müssen besetzt sein. |
| Stellvertretung | Rolle neben dem Vorsitz; beide sind fachlich gleichberechtigt. Die Stellvertretung kennzeichnet ausschließlich die Vertretungsfunktion. |
| Tagesabschnitt | Vormittag, Nachmittag oder ganztägig. Besetzungsregeln gelten je relevantem Tagesabschnitt. |
| Verfügbarkeit | Rückmeldung eines Ausschussmitglieds für einen möglichen Prüfungstag: ganztägig, vormittags, nachmittags, nicht verfügbar oder offen. |
| Vertretungsseite | Arbeitgeber-, Arbeitnehmer- oder Schulseite eines Ausschussmitglieds. Jede Seite muss je relevantem Tagesabschnitt vertreten sein. |
| Vorsitz | Rolle neben der Stellvertretung; beide sind fachlich gleichberechtigt. |
